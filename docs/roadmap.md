# Roadmap — Natuurwaarnemer ERP

Overzicht van geplande en voltooide functionaliteit voor **Natuurwaarnemer ERP**.

---

## Fase 1 — Basis ERP

De kernfunctionaliteit voor facturatie, kosten en boekhouding.

- [x] SQLite database schema
- [x] Volledig Nederlands RGS grootboekschema (0xxx–9xxx)
- [ ] HA invoerscherm facturen
- [ ] n8n factuurflow
- [ ] PDF generatie via Gotenberg
- [ ] Grootboekboekingen automatisch
- [ ] Kostenregistratie
- [ ] BTW-rapport

---

## Fase 2 — Webshop

Koppeling met WooCommerce voor geautomatiseerde orderverwerking.

- [ ] WooCommerce webhook → n8n
- [ ] Orders opslaan in SQLite
- [ ] Automatisch facturen genereren
- [ ] Voorraad bijwerken

---

## Fase 3 — Rapportages

Geavanceerde rapportage en overzichten.

- [ ] Omzet per maand dashboard
- [ ] Kosten per maand dashboard
- [ ] BTW-aangifte rapport
- [ ] Winst &amp; verlies overzicht
- [ ] Jaaroverzicht export

---
